158.258 Web Development - Topic 5 Lab

Contents. Topic 5 set two labs. The first one asks for an XML document describing a book catalogue and a page that fetches and displays it. The second one asks for a JSON document describing a set of user profiles and a page that fetches and displays that as well. Both pages are plain HTML, CSS and JavaScript, so the whole folder can be published on GitHub Pages as it stands.

The two labs

  1. Lab 1 - XML: a book catalogue
    The page fetches book.xml with the fetch API, parses the text with DOMParser, and lists the title, author and price of every book in the catalogue. (xml-lab.html, book.xml, book.dtd, book.xsd)
  2. Lab 2 - JSON: user profiles
    The page fetches userProfiles.json and shows each user's name, email, date of birth, address and preferences. (json-lab.html, userProfiles.json, userProfiles.schema.json)

Running the pages

Open the site through a web address, not from the file system. Both lab pages use the fetch API, and a browser refuses to fetch a data file from a file:// address because that would break the same-origin rule. Opened that way, the page reports the fetch error instead of the table. Either view the published site, or run a small web server in this folder (for example python -m http.server) and open http://localhost:8000/.
